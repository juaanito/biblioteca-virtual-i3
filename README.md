
# Biblioteca Virtual

## Descripción del proyecto

Biblioteca Virtual es un proyecto académico que busca planificar un sistema para administrar libros, usuarios y préstamos de una biblioteca.

## Objetivo

Facilitar la administración de una biblioteca mediante un sistema que permita registrar libros, buscar información, controlar préstamos y gestionar devoluciones.

## Funcionalidades principales

- Registro de libros.
- Registro de usuarios.
- Búsqueda de libros.
- Administración de préstamos.
- Registro de devoluciones.

## Usuarios

- Administrador.
- Bibliotecario.
- Lector.

## Requisitos del sistema
- El sistema debe permitir el registro de nuevos usuarios mediante correo institucional.
-  El catálogo debe actualizarse en tiempo real al realizar un préstamo.
- El sistema debe enviar recordatorios por correo 2 días antes del vencimiento.
- El usuario no podrá reservar más de 3 libros simultáneamente.
- El panel de administración debe mostrar reportes mensuales de préstamos.

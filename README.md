
# Biblioteca Virtual

## Descripción del proyecto

Biblioteca Virtual es un proyecto académico que busca planificar un sistema para administrar libros, usuarios y préstamos de una biblioteca.

## Objetivo

Facilitar la administración de una biblioteca mediante un sistema que permita registrar libros, buscar información, controlar préstamos y gestionar devoluciones.

## Funcionalidades principales

- Registro de libros.
- Registro de usuarios.
- Búsqueda de libros.
- Administración de préstamos.
- Registro de devoluciones.

## Usuarios

- Administrador.
- Bibliotecario.
- Lector.

# Requisitos del sistema

## Requisitos funcionales

- RF-01: El sistema debe permitir registrar libros.
- RF-02: El sistema debe permitir registrar usuarios.
- RF-03: El sistema debe permitir buscar libros por nombre y autor.
- RF-04: El sistema debe permitir registrar préstamos.
- RF-05: El sistema debe permitir registrar devoluciones.

## Requisitos no funcionales

- RNF-01: El sistema debe ser fácil de utilizar.
- RNF-02: La información debe mantenerse organizada.


# Plan de pruebas

## Objetivo

Verificar que las funcionalidades propuestas para Biblioteca Virtual cumplan con los requisitos establecidos.

## Casos de prueba

### CP-01: Registro de libros
- Acción: Registrar un libro con sus datos.
- Resultado esperado: El sistema guarda el libro correctamente.
- Requisito relacionado: RF-01.

### CP-02: Registro de usuarios
- Acción: Registrar un nuevo usuario.
- Resultado esperado: El sistema registra los datos del usuario.
- Requisito relacionado: RF-02.

### CP-03: Búsqueda de libros
- Acción: Buscar un libro por su nombre.
- Resultado esperado: El sistema muestra el libro encontrado.
- Requisito relacionado: RF-03.

### CP-04: Registro de préstamos
- Acción: Registrar el préstamo de un libro.
- Resultado esperado: El sistema registra el préstamo.
- Requisito relacionado: RF-04.

### CP-05: Devolución de libros
- Acción: Registrar la devolución de un libro.
- Resultado esperado: El sistema actualiza la disponibilidad del libro.
- Requisito relacionado: RF-05.

## Conclusión

Los cinco casos de prueba permiten verificar las funcionalidades principales del sistema y su relación con los requisitos.

Nota: Son pruebas planificadas. No se ejecutaron porque la aplicación no fue desarrollada.
